THƯ MỤC ẢNH DANH MỤC SẢN PHẨM
================================

Bỏ ảnh đại diện cho từng danh mục vào đây, ĐẶT ĐÚNG TÊN FILE bên dưới
(định dạng .jpg hoặc .webp đều được, nhưng nên dùng .webp cho nhẹ).

Tên file mong đợi:
  1. terrarium.jpg      -> Danh mục Terrarium
  2. thuy-sinh.jpg      -> Bể cá thủy sinh
  3. cay-de-ban.jpg     -> Cây xanh để bàn
  4. sen-da.jpg         -> Sen đá - Xương rồng
  5. phu-kien.jpg       -> Phụ kiện
  6. workshop.jpg       -> Workshop

Kích thước đề xuất: 800 x 600 px (tỉ lệ 4:3).

LƯU Ý:
- Nếu chưa có ảnh, website sẽ tự dùng ảnh demo (Unsplash) nên không bị vỡ.
- Khi bạn bỏ ảnh đúng tên vào đây và refresh trang, ảnh local sẽ hiển thị.
- Nếu dùng .webp, hãy sửa đuôi file tương ứng trong app.js (mảng PRODUCTS, field "local").
